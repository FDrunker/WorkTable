# 男鞋退换货规则

## 适用范围

本规则适用于本店男鞋商品的退货、换货和售后申请。平台规则、商品详情页承诺或适用法律提供更高标准的，从其规定。定制商品、已明确标注瑕疵处理的特价商品等特殊商品，以购买页面展示规则为准。

## 基本申请条件

- 商品应保持完好，鞋面、鞋底、鞋垫、吊牌、鞋盒和赠品尽量齐全。
- 试穿应在室内干净地面进行，避免鞋底磨损、沾水、沾泥或产生明显使用痕迹。
- 退换前请先提交申请并获取售后地址，不要直接将商品寄回发货地址。
- 顾客应保留寄回物流单号、寄出照片和退货包裹信息。
- 超过平台申请时效、无法核实订单或商品被严重使用影响二次销售的，可能无法按无理由退换处理。

## 七天无理由退货

### 适用情况

顾客对颜色、款式、搭配效果或个人喜好不满意，商品不影响二次销售时，可按订单页显示的时效申请无理由退货。具体是否支持七天、退货地址和运费承担方式，以平台规则和结算页为准。

### 商品状态要求

- 鞋底无明显磨损、泥沙、水渍和油污。
- 鞋面没有严重折痕、划痕、变形或自行修补痕迹。
- 吊牌、鞋盒、防尘袋、鞋带和赠品尽量完整。
- 不得影响商家再次销售，不得有明显穿着外出痕迹。

### 运费说明

无理由退货的往返运费通常由顾客承担；若商品页面、平台活动或客服承诺包退，则按对应承诺执行。运费险是否赔付以保险审核结果为准。

### 标准回复

> 您可以在订单页申请无理由退货，商品需要保持未外出穿着、鞋底无磨损且配件完整。具体时效和运费以订单页规则为准。寄回前请先提交申请，我们确认后会发送退货地址。

## 质量问题退换货

### 适用情况

商品存在开胶、断底、结构开裂、严重掉色、明显配货错误或其他影响正常穿着的问题，经照片、视频或质检确认后，可优先安排退货、换货或维修。

### 处理优先级

1. 刚签收即发现且证据明确时，优先换货或退货。
2. 影响安全的结构问题，优先停止使用并升级审核。
3. 可维修的问题，可先与顾客确认维修方案和时效。
4. 无法通过照片确认的问题，可协商寄回质检。

### 运费说明

经确认属于质量问题或商家发错货的，寄回运费由商家承担或按平台售后流程处理。顾客先垫付运费的，应保留支付凭证和物流单号，审核通过后按承诺报销。

### 标准回复

> 如果核实属于质量问题，我们会优先为您安排换货、退货或维修。请您先提供订单号和问题部位照片，确认后再寄回；未经确认请勿直接到付寄件。

## 换货规则

- 换货前需确认目标颜色和尺码是否有库存。
- 同一订单仅支持按平台规则申请一次或有限次数的换货。
- 因尺码不合适换货时，应重新核对脚长、脚宽和鞋楦建议。
- 换货商品经检查影响二次销售时，商家可能拒绝换货或改为维修方案。
- 无库存时可协商退款、更换其他款式或等待补货。

### 标准回复

> 目前可以帮您先核对需要更换的颜色和尺码库存。确认有货后，请在订单页提交换货申请；商品检查合格后会安排重新发出，具体到货时间以物流为准。

## 不支持退换或需审核的情况

| 情况 | 说明 |
| --- | --- |
| 已明显外出穿着 | 鞋底泥沙、磨损、水渍会影响二次销售判断 |
| 人为损坏 | 刀割、火烧、化学品腐蚀、自行涂胶或修补 |
| 非正常使用 | 高强度运动、雨天长时间浸泡、高温暴晒 |
| 超过申请时效 | 以订单页和平台售后规则为准 |
| 配件或包装严重缺失 | 可能影响退货金额、换货或二次销售 |
| 定制或特殊商品 | 以商品详情页明确标注的规则为准 |
| 无法提供必要凭证 | 无法核对订单、商品状态或物流责任 |

## 退换货流程

### 第一步：顾客提交申请

顾客应在订单页选择退货或换货，并填写原因。涉及质量问题时，应同时上传整体照片、问题部位近照、鞋底照片或视频。

### 第二步：客服审核

客服核对订单、售后时效、商品状态和证据。证据不足时，应一次性说明需要补充的材料。

### 第三步：顾客寄回

审核通过后，客服提供正确退货地址。顾客寄回时应保留物流单号，并拍摄商品、配件和包装的寄出照片。

### 第四步：仓库质检

仓库检查鞋面、鞋底、配件、吊牌和鞋盒状态，确认是否与顾客描述一致，并记录开箱结果。

### 第五步：退款或换货

退货审核通过后，退款按原支付渠道处理；换货审核通过后，按库存情况重新发货。被拒收或需要补差额时，应向顾客说明具体原因。

## 常见问题回复

### 顾客问能不能直接寄回

> 请先不要直接寄回。不同原因对应的退货地址和处理方式可能不同，先提交平台售后申请，我们会发送准确地址，避免包裹无法签收。

### 顾客问能不能到付

> 质量问题是否支持到付要以审核结果为准。未经确认的到付包裹可能被拒收。建议您先联系客服确认寄回方式和运费责任。

### 顾客问退款多久到账

> 仓库确认收货并审核通过后，我们会提交退款。到账时间取决于支付渠道，通常以平台页面显示的预计时间为准。

### 顾客问能不能换其他款

> 可以先把想更换的款式、颜色和尺码发给我，我帮您核对库存和差价。确认后再按平台流程提交换货或退货重拍。

### 顾客问只退一双可以吗

> 如果订单包含多双鞋，是否可以部分退货取决于平台规则和商品是否可单独核算。请先说明要退的商品和原因，我们帮您核对。

### 顾客对审核结果不满意

> 理解您对结果有疑问。请告诉我您的订单号和期望方案，我们会复核照片、质检记录和适用规则；如仍有争议，可以继续通过平台售后申诉。

## 客服注意事项

- 不得口头承诺平台规则之外的退款金额、运费赔偿或到货时间。
- 不得要求顾客撤销平台售后申请后私下处理。
- 不得使用“肯定能退”“一定能赔”等绝对化表达。
- 涉及质量问题时应先收集证据，再判断方案。
- 顾客信息、订单信息和收货地址应严格保密。
